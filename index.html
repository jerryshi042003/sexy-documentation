Illustrative release process

Manual release

  1. AnalystExport the approved file
  2. AnalystUpload to the target workspace
  3. AnalystCheck settings and refresh
  4. Report ownerReview the published result

Each handoff depends on someone repeating the procedure.

Pipeline release

  1. AnalystCommit the approved change
  2. PipelineValidate and deploy to the target
  3. PipelineApply configured checks
  4. Report ownerReview the published result

Repeatable deployment; business acceptance stays explicit.
