    How a dollar gets a cause

    The order causes are assigned in
    1. Match rows by sale id and line between the comparator and the current run.
    2. Rows only in the current run are late or backfilled, or after the comparator's cutoff.
    3. Matched rows that the current run holds for review are review holds.
    4. Matched rows paid to a different rep are rep attribution.
    5. Whatever remains on matched rows is rounding and allocation. If that bucket is larger than one cent per row, stop and investigate instead of netting it.
