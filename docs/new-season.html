New season setup

Add the season's event codes and product rules before the first sale. The nightly ticket job builds everything else; check it the next morning.

Younext morning
3Run the three checks
Optionalany time
Opponents Theme nights

Required

  1. Add every event code for the season to raw.ticket_setup.event_season_map. This table is the only source of an event's season. Without it, events, seasons and products will not line up, and sales land with no season.
  2. Update the season's product rules in raw.ticket_setup.price_code_rules. Summit HC maps price codes to products here. Harbor FC maps by section and needs no change unless it adds a product.

Runs automatically

Once the season is in event_season_map, the nightly ticket job rebuilds these four tables. You do not need to rerun them.

  • curated.tickets.event_dim
  • curated.tickets.season_dim
  • curated.tickets.product_dim
  • curated.mapping.item_product

Optional

Fill these when the business wants the extra attributes. They feed event_dim only and never decide whether a sale is counted.

  • raw.ticket_setup.event_opponent
  • raw.ticket_setup.theme_nights

When code has to change

The season key is outside the supported range

Supported season keys are listed in product_dim/seed.py. Add the new key there; the job skips keys it does not know.

The season adds a new product, category or sub-category

Add it to the product list in product_dim/seed.py and to the report groupings that read it.

A Summit HC rule cannot be written as a price-code row

For example, a product that depends on both price code and seat section. Update mapping/item_product.py until the rules table can express it.

Validate

Run the morning after the nightly job. Each query should return rows for the new season.

-- 1. The event codes are mapped
select event_code, season_key
from raw.ticket_setup.event_season_map
where season_key = 'S27';

-- 2. The season exists for both clubs
select club, season_key
from curated.tickets.season_dim
where season_key = 'S27';

-- 3. Products were built
select club, season_key, count(*) as products
from curated.tickets.product_dim
where season_key = 'S27'
group by 1, 2;

If all three return rows and item_product still misses the season, look next at the Summit HC price-code rules in step 2.
